# InsightHub 使用指南

本指南按 UI 当前支持的收集、知识库、搜索、问答、笔记和设置流程介绍基本用法。不同 Provider 的模型与工作流取决于管理员配置。

## 1. 收集资料

在「收集」页选择 URL、文本或文件。提交后可在「最近收集」或知识库查看处理状态。网页需要由 InsightHub 服务端获取；登录墙、反爬策略或不可达站点可能无法提取，请使用有权提供的文本或文件补充，不要把 URL 本身当作正文。

## 2. 知识库与分析

知识库保存来源、提取结果及可用的分析内容。打开资料详情查看原始来源、提取状态、摘要和证据。只有实际返回并通过相应校验的内容才是分析结果；模型可用性受工作流路由、凭据、额度和资料状态影响。

## 3. 搜索与问答

使用搜索查找已保存资料；若启用了 Embedding，可参与语义检索，否则关键词检索仍可用。在问答页提交问题，回答会显示可回溯的资料引用。回答是基于检索上下文生成的辅助内容，需按引用核对原文。

## 4. 笔记

笔记页按时间和资料范围预览可用资料，可选主题与生成详细程度，然后预览资料并提交生成。生成结果与任务状态由后端保存；排队和运行中的任务需等待终态。按页面提示处理部分成功或失败，不要把失败任务当作已保存笔记。

## 5. 设置 Provider

在「设置 → AI 模型」查看已注册 Provider、Deployment、路由和凭据状态。模型 Key 通过加密 Vault 配置。配置某个 Provider 并不自动代表所有工作流都指向它；检查实际路由和模型测试结果。MiniMax 配图是独立可选能力；项目的本地安全上限不等于供应商剩余额度。

## 隐私与备份

云端模型会接收其工作流所需的输入。勿发送不应外传的资料。备份数据库和 `app_data` 卷时应作为一组保护；其中包含用户上传、派生资产以及加密凭据主密钥材料。参阅[部署说明](DEPLOYMENT.zh-CN.md)。
